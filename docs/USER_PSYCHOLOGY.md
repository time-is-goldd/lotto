# USER PSYCHOLOGY — 시간대별 심리 변화 및 훅 설계

> v2.0 개정. [[MASTER_PRD]] §0 재정의("핵심은 번호생성이 아니라 행운 다이어리")에 맞춰 5~10분 구간의 "투자" 메커니즘을 다이어리 중심으로 명확히 했다. 기능 나열이 아니라 "사용자의 머릿속에서 무슨 일이 일어나는가"를 시간 축으로 분석하고, 각 순간마다 다음 클릭을 유도하는 장치를 설계한다.

---

## 1. 심리 모델: AIDA + 습관고리(Hook Model) 결합

본 서비스는 Nir Eyal의 Hook Model(계기→행동→가변보상→투자)을 로또의 본질적 주간 반복 리듬에 결합한다.

```
외부 계기(검색/공유) → 내부 계기(궁금증/불안) → 행동(번호생성 클릭) 
   → 가변보상(번호+운세+사회적비교) → 투자(저장/가입/공유) → 다음 계기 재생성(당첨알림)
```

---

## 2. 시간대별 심리 변화 분석

### 0~5초 — "여기 맞나?" (신뢰 판단 구간)
**심리 상태**: 검색 결과를 클릭하고 막 도착. 이 사이트가 광고로 도배된 저질 사이트인지, 신뢰할 만한 곳인지 무의식적으로 0.05초 만에 1차 판단.

**행동 설계**:
- 첫 화면에 광고 배너 없음 (최소한 스크롤 없이 보이는 영역, Above the Fold는 클린하게)
- 화면 중앙에 "번호 생성하기" 대형 버튼 1개만 강조 — 선택지 과부하 방지
- 신뢰 신호: "이번주 12,483명이 생성했어요" 같은 사회적 증거를 버튼 하단에 배치

**목표**: 이탈하지 않고 버튼을 누르게 만든다.

### 5~30초 — "오 재밌네" (즉각 보상 구간)
**심리 상태**: 버튼을 눌렀고, 번호가 나왔다. 이 순간이 전체 여정에서 가장 중요한 "첫 도파민 지점"이다. 여기서 시시하면 바로 이탈한다.

**행동 설계**:
- 번호가 뜨는 과정을 로또 볼이 굴러나오는 듯한 애니메이션으로 연출 (실제 추첨 방송의 긴장감 모사)
- 결과 직후 "한 번 더 뽑기" 버튼을 바로 옆에 배치 — 재생성 자체가 재미(게임화)
- 동시에 우측/하단에 "실시간으로 다른 사람들이 뽑은 번호" 피드가 흐름 — 나 혼자가 아니라는 감각(사회적 존재감)이 체류시간을 늘림

**목표**: 최소 2회 이상 번호를 재생성하게 만든다 (재생성 = 참여 몰입의 증거).

### 30초~2분 — "이것도 있네?" (발견 구간)
**심리 상태**: 번호 생성은 이미 했다. 목적은 달성했지만 아직 떠날 이유도 없는 애매한 상태 — 이 구간에서 다음 흥미거리를 "발견"하게 만들지 못하면 이탈률이 급증한다.

**행동 설계**:
- 결과 화면 바로 아래(스크롤 최소화) "오늘의 운세도 궁금하세요?" 카드 — 로또와 자연스럽게 연결되는 콘텐츠(운세는 로또 사용자의 잠재 니즈)
- "지난주 1등, 이 지역에서 나왔어요" 같은 국지적 호기심 자극 카드 → `/winners`
- 꿈해몫 검색 유입자라면 이미 이 경로를 거쳐왔으므로, 반대로 "번호생성 유입자에게는 꿈해몽을" 교차 추천

**목표**: 최소 1개의 추가 콘텐츠 페이지로 이동시킨다 (2페이지 이상 = 체류 목표 달성).

### 2~5분 — "나도 참여하고 싶다" (참여·비교 구간)
**심리 상태**: 콘텐츠를 몇 개 구경했다. 이제 "구경꾼"에서 "참여자"로 전환될지 결정되는 구간. 인간은 관찰만 하면 금방 지루해지고, 비교 대상이 생기면 몰입한다.

**행동 설계**:
- 이번주 배틀 소개: "당신의 번호로 도전해보세요, 1등에게는 OO 보상" — 경쟁 심리 자극
- 명예의 전당 노출: "이번주 랭킹 1위는 몇 등수까지 맞췄을까?" 클릭 유도형 카피
- 이 시점에 처음으로 로그인 요구 (번호 생성/열람은 계속 무료, 배틀 참여·저장부터 로그인 요구) — 이미 3분 이상 몰입한 사용자는 가입 마찰을 훨씬 낮게 느낌 (매몰비용 효과)

**목표**: 회원가입 전환.

### 5~10분 — "이건 내 다이어리다" (투자·소유 구간, 개정)
**심리 상태**: 이미 가입했고, 번호도 생성했다. 이 시점부터는 "사이트를 이용했다"가 아니라 **"내 행운 다이어리에 첫 페이지가 생겼다"**는 소유감으로 프레이밍해야 한다. Hook Model의 "투자" 단계는 v1.0에서는 막연히 "사이트가 내 것을 갖고 있다"는 감각이었지만, v2.0에서는 그 대상을 명확히 **행운 다이어리**로 지정한다 — 대상이 구체적일수록 소유감이 강해진다.

**행동 설계**:
- 다이어리 화면에서 "이번주 토요일 추첨 후 자동으로 기록해드릴게요" 명시적 약속 문구 → 미래 재방문 예약
- 알림 수신 동의 유도("당첨되면 가장 먼저 다이어리에 표시돼요")
- 공유 유도: "이 기록, 카톡으로 자랑해보세요"
- 다이어리를 "번호만 있는 곳"이 아니라 "꿈도, 운세도 기록할 수 있는 곳"으로 인지시키는 넛지: "오늘 꾼 꿈도 남겨보세요" — 낮은 허들의 추가 기록 행동 유도(번호 생성 없이도 다이어리를 채우는 습관 형성)

**목표**: 알림 동의 + 공유 1회 + 다이어리에 번호 외 기록(꿈/운세) 1건 추가 + 익주 재방문 의도 형성.

## 3. 반복 방문 심리 (Week 2 이후)

로또의 본질은 "주간 리듬"이다. 이 리듬을 서비스가 선점해야 한다.

| 요일 | 사용자 심리 | 서비스 대응 |
|---|---|---|
| 월~수 | 아직 관심 낮음 | 콘텐츠(꿈해몽/통계) 열람 위주, 이메일/알림 최소화 |
| 목~금 | 이번주 번호 슬슬 정해야 함 | "이번주 번호 아직 안 만드셨나요?" 리마인드 알림 |
| 토요일 저녁(추첨) | 기대감 최고조 | 추첨 카운트다운 배너, 실시간 추첨 결과 알림 예약 유도 |
| 토요일 밤~일요일 | 당첨 확인 강박 | 당첨 자동확인 + 결과 알림 즉시 발송 → 재방문의 핵심 트리거 |
| 일요일 | 다음 주 준비 심리 전환 | "다음 주 번호는 이렇게 뽑아보세요" 콘텐츠 추천 |

이 주간 사이클을 콘텐츠 발행/알림 스케줄과 정확히 맞추는 것이 [[CONTENT_STRATEGY]]의 핵심 전제다.

**Luck Platform 확장 관점 (신규)**: 월~수처럼 로또 관심이 낮은 구간은 로또 단일 서비스라면 이탈 위험 구간이지만, Fortune(운세)·Dream(꿈해몽) 브랜치는 요일과 무관하게 매일 소비될 수 있는 콘텐츠다. 다이어리에 "오늘의 운세도 확인해보세요"를 월~수 구간에 우선 노출함으로써, 로또 주기와 무관하게 매일 방문할 이유를 만든다 — 이것이 단일 로또 서비스 대비 Luck Platform 구조가 갖는 구조적 리텐션 우위다.

## 4. 감정 곡선 요약도

```
신뢰판단(0-5s) → 첫도파민(5-30s) → 호기심발견(30s-2m) → 경쟁몰입(2-5m) → 소유감(5-10m) → 주간습관화(W2+)
    ↓                ↓                    ↓                  ↓               ↓                ↓
  이탈방지         재생성유도            2페이지+ 이동        가입전환         공유+알림동의      재방문 루프 완성
```

## 5. 심리 설계 원칙 (금지 사항 포함)

1. **선택지는 항상 최대 3개**: 시니어 사용자는 선택지가 많으면 얼어붙는다(Paradox of Choice). CTA는 항상 주/보조 2단계로 제한.
2. **로딩은 짧고 즐거워야**: 번호 생성 로딩이 1초 미만이면 오히려 "성의 없어 보임" — 0.8~1.2초의 애니메이션 딜레이를 의도적으로 삽입해 기대감을 형성 (단, 절대 3초를 넘기지 않음).
3. **사회적 증거는 항상 실시간처럼**: "지금 342명이 접속 중" 등 실시간성이 체류 욕구를 자극. 단, 과장/허위 수치 금지 — 실제 집계 기반으로 설계 ([[FEATURE_SPEC]] §11).
4. **부정적 결과(미당첨)에도 다음 행동 제시**: 실망으로 끝나는 화면을 만들지 않는다. 항상 다음 루프로 연결.
5. **사행성 자극과 재미의 경계 준수**: "인생역전" 식 자극 대신 "이번 주도 재미있게" 톤 유지 — [[MASTER_PRD]] 비목표 원칙과 일치.
